Icon Placeholders
=================

You'll need to create icons in the following sizes:
- icon16.png (16x16)
- icon32.png (32x32)
- icon48.png (48x48)
- icon128.png (128x128)

For now, you can use a simple placeholder or the UW-Madison Badger logo.
I recommend creating a red/white design that matches the Wisconsin branding.

You can use a tool like:
- Figma
- Canva
- GIMP
- Or any online icon generator
